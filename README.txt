勉強アプリ（漢字スキャン・ローカルカメラ対応版）

カメラの使い方
1. ZIPを展開し、index.htmlをChromeまたはEdgeで開きます。
2. 漢字の問題ファイルを開き、「教科書から漢字問題を作成」を表示します。
3. 「カメラを起動」を押してブラウザのカメラ使用を許可します。
4. 熟語を映し「撮影して取り込む」を押します。
5. 画像上で熟語の範囲をドラッグして囲み、「囲んだ範囲を読み取る」を押します。
6. 読み取った漢字とひらがなの読みを確認・修正し、「確認した熟語を問題に追加」を押します。

ローカルファイルでのカメラ利用について
・HTTPSのGitHub Pagesに公開しなくても、Chrome/Edgeなどでローカルのindex.htmlを直接開いてカメラを起動できる環境があります。
・ただし file:// のカメラ利用はブラウザやOSの設定に左右されます。ブラウザが拒否した場合、このHTMLだけで制限を解除することはできません。その場合はPC内でlocalhostとして開くかHTTPSで開いてください。
・初回の日本語OCRはTesseract.jsと言語データをCDNから取得するため、インターネット接続が必要です。カメラ撮影自体はネット接続不要です。
・OCRの読み取り間違いを防ぐため、ひらがなの読みは確認・入力してから登録します。
