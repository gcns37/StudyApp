勉強アプリ 更新版

GitHub Pages の公開フォルダに、このフォルダ内の6ファイルをすべて配置してください。
index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png / apple-touch-icon.png

変更点
1. 英語の問題編集画面では画像アップロード欄を表示せず、英単語と日本語の意味だけで問題を作成できます。既存の画像情報は保持します。
2. 学習の進捗は、覚えた回数が2回以上の問題数 ÷ 有効な問題の合計数 × 100% で表示し、問題や記録の変更に合わせて更新します。
3. 覚えた機能がOFFの場合、ゲージの代わりに「覚えた機能がオフです」と表示します。
4. オフライン利用用のサービスワーカーを v7 に更新しました。

既存のlocalStorageキーとバックアップ形式は維持しています。
