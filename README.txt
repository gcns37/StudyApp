勉強アプリ 更新版

今回の変更
・漢字の学習画面に「ペン」「消しゴム」を追加しました。
・ペンは通常の黒線、消しゴムはドラッグした部分だけを消します。
・「全消去」で書いた内容をすべて消せます。
・答えの文字は問題の文字サイズの3倍を基準に表示し、表示枠に収まらない場合は自動で縮小します。
・問題編集画面／学習画面の問題タイトルが長い場合、タイトル部分で折り返し・最大2行表示にし、画面幅を押し広げないようにしました。タイトル全体はマウスを乗せると確認できます。
・前回の漢字スキャン、ローカルカメラ対応、間違えたら次の問題へ進む機能を維持しています。

使い方
1. ZIPを展開します。
2. 中のファイル一式を、現在のアプリのファイル一式と入れ替えてください。
3. GitHub Pagesを使っている場合は、index.html・manifest.webmanifest・sw.js・アイコン画像をまとめて更新してください。
4. ブラウザに古い画面が残る場合は、再読み込みしてください。

注意
・ペン／消しゴムは漢字の学習画面に表示されます。
・答えの文字サイズは問題文字の3倍を初期値とし、枠からはみ出すときだけ自動縮小します。
・日本語OCRの初回読み込みにはインターネット接続が必要です。
