勉強アプリ（漢字スキャン機能 実装版）

使い方
1. HTTPSでアプリを開き、教科を「漢字」にして問題ファイルを開きます。
2. 「教科書から漢字問題を作成」で撮影または画像を選択します。
3. 画像上で熟語がある部分をドラッグして囲み、「囲んだ範囲を読み取る」を押します。
4. OCRで抽出された漢字を確認し、各熟語の読みをひらがなで入力します。
5. 「確認した熟語を問題に追加」を押すと、ひらがなが問題、漢字が答えとして保存されます。

注意
・日本語OCRはTesseract.jsをCDNから読み込むため、初回の読み取り時にインターネット接続が必要です。
・カメラ撮影にはHTTPSなど安全な接続とカメラ権限が必要です。
・OCRは誤認識することがあります。読みと漢字を確認してから追加してください。読みは自動推測せず、確認入力方式です。
・答え表示は全教科で中央揃えです。
