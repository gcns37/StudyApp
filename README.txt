今回の変更
1. 答えの文字を前回の約5倍に拡大（PC 180px、スマホ 140px）。
2. 設定にGitHub保存・読み込みを追加。
3. GitHub保存は同じパスのファイルがあればSHAを取得して上書きし、なければ新規作成。
4. GitHubからの読み込みは全教科バックアップを確認してから現在のデータを置き換えます。
5. サービスワーカーのキャッシュ名をv8に更新。

GitHub連携の設定
- GitHubユーザー名/組織名、リポジトリ名、ブランチ、保存パスを入力します。
- 保存にはGitHubアクセストークンが必要です。Fine-grained personal access tokenを使い、対象リポジトリだけに限定し、Contentsの読み書き権限を付けてください。
- トークンはアプリのlocalStorageやバックアップには保存しません。ページを再読み込みすると再入力が必要です。
- 公開リポジトリの読み込みはトークンなしでも可能です。非公開リポジトリの読み込みには読み取り権限付きトークンが必要です。
- GitHub Pages自体にサーバー機能はありません。GitHub APIをブラウザから呼び出して保存します。
- トークンを他人に見せたり、公開リポジトリに書いたりしないでください。

既存の学習データ保存形式とlocalStorageキーは維持しています。
